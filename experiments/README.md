# Experiments

This directory stores reproducible experiment records and small supporting artifacts.

Each experiment should:

- have a unique experiment ID;
- state the question and hypothesis before the result;
- point to a frozen config;
- identify exact model/tokenizer revisions;
- record hardware and runtime versions;
- preserve raw metric paths or immutable artifact references;
- document confounders and negative results.

Use `research/experiment-template.md` for narrative records.

Do not organize experiments as personal weekly diaries. Organize them by technical question.
