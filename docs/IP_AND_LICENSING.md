# IP & Licensing Strategy

This repository is public because reproducibility, external validation, and community use are core goals. Public visibility does **not** mean every future commercial/IP decision has already been made.

## Current state

No final software license has been selected for the repository yet.

Until a license is deliberately chosen, do not assume that public source code grants broad reuse rights beyond the platform's default terms.

## Intended product philosophy

Long-term preference:

- individual/local users: broad free access;
- education and non-commercial research: broad free access;
- commercial/enterprise deployment: preserve a path to paid licensing/support;
- genuinely novel patentable work: evaluate protection **before** public disclosure.

## Important terminology

A license that prohibits commercial use is generally **source-available**, not Open Source Initiative-style open source.

If the project wants to remain genuinely open source while creating commercial licensing pressure, one path to evaluate is a copyleft license plus a separate commercial license. That is a legal/business decision, not something to improvise in a README.

## Decision gate before v0.1 release

Before adding a final `LICENSE` file, explicitly evaluate:

1. Is the primary goal maximum adoption or maximum commercial control?
2. Is eligibility for open-source support programs important?
3. Does the code contain a genuinely novel method worth a prior-art/patent review?
4. Would a strong copyleft license create enough commercial friction?
5. Is a source-available personal-use/free-commercial-paid model preferable even if it cannot honestly be called open source?
6. Are model/tool dependencies compatible with the selected license?

## Novel-IP rule

If experiments uncover a method that appears both:

- materially better than known approaches; and
- plausibly novel/non-obvious,

then pause public disclosure of that **new mechanism** long enough to perform a serious prior-art and IP review.

Do not retroactively discover that the patent strategy died in a celebratory GitHub commit. Humanity has already performed that experiment for us.

## No legal claim

This document records project strategy, not legal advice. Any serious commercial/patent decision should be reviewed by qualified counsel before relying on it.
